# Community Jibo skills

No publicly released skill is included yet. The current `Talk to NOVA` robot integration is designed for a private deployment and **is not suitable for redistribution as-is**.

Public skill candidates must be independently installable, must not contain home network details, secrets, device identifiers or private service endpoints, and must have permission to redistribute all bundled code and dependencies. Build a skill ZIP with the 5x1/BEacon skill format, a clear installation guide, a maintenance policy and a separate threat review before adding it here.

Never mirror or copy runtime folders from a working robot into this public project.
