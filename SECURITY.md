# Security policy

This repository is a public distribution of declarative Jibo eye themes. It intentionally excludes private assistant gateways, tokens, configuration, robot logs and system backups.

If you discover a security problem, do not post live secrets in a public GitHub issue. Contact the project maintainer privately through their GitHub profile before sharing sensitive evidence. If credentials are accidentally exposed in a public commit, revoke and rotate them immediately; deleting a file from a later commit is not sufficient.

The static secret scanner and release validators are safeguards, not a guarantee that unknown encodings or supply-chain dependencies are risk-free.
