# Security policy

This public repository is only for shareable Jibo themes and independently audited skills.

Never contribute personal NOVA/OpenClaw configuration, passwords, tokens, certificates, device identifiers, home network addresses, logs, backups, or private repository history.

**Talk to NOVA** and the home adapter are not approved for publication until the executable code, third-party licensing, and data-handling have been reviewed separately.

If you discover a potential credential exposure, contact the maintainer privately rather than filing a public issue with secrets. Exposed secrets should be revoked or rotated; removing a file does not purge git history.
